# Ninja Pajamas — Cinema Ticketing System

An online cinema ticketing platform with seat selection, e-tickets, and QR code scanning.

## Features

- User Registration & Login
- Cinema Events Page
- Event Details Page (CIN-4 — Nizomiddin)
- Interactive Seat Selection
- Prevent Double Booking
- Online Payment
- E-Ticket Generation
- QR Ticket Scanner
- Seat Categories
- Ticket History
- Security & Roles
